# 🙏 Venkateshwara Kattela Adithi

## Daily Accounts & Expense Tracker

Venkateshwara Kattela Adithi is a simple daily accounts application designed to record and track business income and outgoing amounts.

### Features

- 🧾 Serial number for every entry
- 📅 Date-wise records
- 💰 Income
- 📈 Investment
- 🛒 Daily spending
- 💵 Automatic running balance
- ✏️ Edit entries
- 🗑️ Delete entries
- 📊 Total income
- 📊 Total investment
- 📊 Total daily spending
- 💰 Current balance
- 💾 Data is saved on the device

### Balance Calculation

The app automatically calculates:

**Previous Balance + Income − Investment − Daily Spending = Current Balance**

Each new entry is added to the previous balance, so you can see the running total every day.

### How to Use

1. Select the date.
2. Enter the income.
3. Enter the investment amount.
4. Enter the daily spending amount.
5. Tap **Save Entry**.
6. The app automatically calculates the new balance.
